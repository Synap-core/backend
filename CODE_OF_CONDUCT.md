# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies to everyone taking part in the project's spaces: this repository's
issues and pull requests, and the project's community channels.

In short: be respectful and considerate, welcome people of every background and
level of experience, and accept constructive feedback. Harassment, personal
attacks and publishing other people's private information are not acceptable.

## Reporting

To report behaviour that breaks this code, email **support@synap.live**. Reports
are read by the project maintainers and handled in confidence. The maintainers
enforce the code following the Contributor Covenant's enforcement guidelines,
from a private warning up to a permanent ban.
